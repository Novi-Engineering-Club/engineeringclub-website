RC car

Model:Tamiya TT02 BR Racing Buggy

About:In 2024, we built a competition level RC brushless RC buggy. It is built on the TT02 platform with a 4WD drivetrain.

Info:The buggy is powered by HobbyWing power systems (ESC) and runs a powerful, sensorless 4000Kv HobbyWing Quicrun brushless motor. It also utilizes a high-torque 15Kg steering servo along with a Spektrum radio system. The buggy runs on 3S power since it is designed to be raced in a modified class.

What we achieved:We built the buggy, and competed for the first time as a team.

3D Printed Airplane (1)

Model:Eclipson Model T

About: In 2025, we are building a RC airplane that is entirely 3D printed. We are using cutting-edge manufacturing technologies to quickly build the parts, and assemble them.

Info:The plane has a 1.2 meter wingspan, and is powered by a SunnySky 1250 Kv brushless outrunner motor with a Hobbypower 30A flight controller. We are using Radiolink T8FB transmitter with the R8EF receiver. The plane runs on 3S power.

What we achieved:We are still building the plane, but we have a fully assembled airframe and are soon going to start the wiring process. We should be done early December 2025.
